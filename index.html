● 7. EKSPOR

Semakin kecil angka CRF, semakin tinggi kualitas dan semakin besar ukuran file. CRF hanya berlaku untuk ekspor MP4 H.264.

MP4 memakai encoder H.264 berbasis frame untuk menghindari keterbatasan codec MP4 bawaan browser. Preset kualitas mengatur CRF dan bitrate sesuai resolusi. Proses ini membutuhkan koneksi internet saat pertama kali memuat FFmpeg.wasm.

Normal: seluruh efek dekoratif diproses. TURBO: mengurangi partikel, kilau dekoratif, dan beban bayangan; resolusi, FPS, durasi, serta animasi utama tetap mengikuti pengaturan.

Versi Web ProRes: WebM direkam langsung oleh browser; MP4 H.264 dan MOV ProRes 4444 diproses dengan FFmpeg.wasm lokal dari website; PNG Sequence ZIP mempertahankan transparansi.

TROZAL MOTION · WEB FREE
• Aplikasi berjalan langsung di browser; tidak memerlukan launcher, PowerShell, Python, atau FFmpeg desktop.
• WebM direkam menggunakan MediaRecorder browser.
• MP4 H.264 dan MOV ProRes diproses di browser, tanpa server encoding.
• MOV memakai ProRes 4444 profile 4, pixel format yuva444p10le, dan alpha_bits 16. Aktifkan latar transparan jika membutuhkan alpha.
